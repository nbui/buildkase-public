# buildkase-public

Public Mac downloads for Buildkase. The app source stays in the private repository.

Releases on this repo hold the disk image, the zip, and `latest-mac.yml`. The site downloads [Buildkase-mac-arm64.dmg](https://github.com/nbui/buildkase-public/releases/latest/download/Buildkase-mac-arm64.dmg) from the latest release.
